# Vehicle Detection Training

This folder contains the training configuration and documentation for the SICK7 aerial vehicle detection model.

## Dataset
VisDrone2019-DET

## Classes
- 0: car
- 1: truck
- 2: bus
- 3: motorcycle

## Model
YOLOv8n

## Training Platform
Kaggle GPU (Tesla T4)

## Dataset Source
VisDrone2019-DET

The trained model weights are not stored in this GitHub repository.

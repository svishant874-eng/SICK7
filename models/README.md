# SICK7 Models

This folder contains documentation for the trained SICK7 detection models.

## Vehicle Detection Model
YOLOv8n trained on VisDrone2019-DET for aerial vehicle detection.

Classes:
- car
- truck
- bus
- motorcycle

## Person Detection Model
A separate YOLOv8n model will be trained for aerial person detection.

Model weights (.pt) are excluded from GitHub using .gitignore.
